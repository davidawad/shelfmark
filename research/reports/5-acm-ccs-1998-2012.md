# ACM CCS 1998 to CCS 2012: is there an official mapping?

Researched 2026-10-10. Read-only research; nothing was implemented. Live acm.org,
dl.acm.org and cacm.acm.org pages return HTTP 403 (a browser challenge) to scripted
clients, so ACM pages were read from Wayback Machine snapshots. Each citation gives the
live URL and the snapshot used. The CCS 2012 SKOS file came straight from dl.acm.org.
"Quote" means verbatim text from the fetched page. I am not a lawyer.

## Finding

**ACM publishes no CCS 1998 to CCS 2012 mapping.** ACM says it built a mapping and ran it
over the ACM Digital Library internally. What it publishes is only the CCS 2012 tree:
SKOS, Word and HTML. None of those files carries 1998 codes or links to them. The only
public trace of the mapping is the pair of 1998 and 2012 terms on each article's DL
citation page. ACM's DL policy forbids harvesting that metadata with scripts.

Per the task rules, no mapping was invented or hand-built. The `acm-ccs` gold labels stay
unscored, as in `bench/results/2026-10-10-r3/results.md` (`acm-ccs-gold`: no corpus
label is a code of the scheme). No `bench/results/2026-10-10-r4/` run was made.

## Evidence

1. **ACM says a mapping exists, but only as DL display.** CACM news item "Major Update to
   ACM's Computing Classification System" (Nov 2012). Quote: "The old CCS scheme has been
   mapped to the new, and both the 1998 and 2012 terms are available on Citation Pages of
   all indexed articles." The item links only the 2012 downloads (`dl.acm.org/ccs/skos`,
   `/word`, `/html`) and no mapping file.
   - https://cacm.acm.org/news/major-update-to-acms-computing-classification-system/
     (snapshot https://web.archive.org/web/20250317215533/https://cacm.acm.org/news/major-update-to-acms-computing-classification-system/)
2. **The CCS 2012 page lists only 2012 formats.** Quote (2015 snapshot): "The full CCS
   classification tree is freely available for educational and research purposes in
   these downloadable formats: SKOS (xml), Word, and HTML." The 2024 version of the page
   says "... in HTML format." Neither version links a 1998 crosswalk.
   - http://www.acm.org/about/class/2012 (snapshot https://web.archive.org/web/20150116070405/http://www.acm.org/about/class/2012)
   - https://www.acm.org/publications/class-2012 (snapshots https://web.archive.org/web/20240108155744/https://www.acm.org/publications/class-2012 and https://web.archive.org/web/20241222222257/https://www.acm.org/publications/class-2012)
3. **The CCS 2012 introduction describes the changes in prose only.** For example:
   "The 1998 classification had reliability and testing approaches, design aids, and
   performance analysis tools listed multiple times". It explains how branches were
   restructured, with no code-level table.
   - https://www.acm.org/publications/class-2012-intro (snapshot https://web.archive.org/web/20241213092351/https://www.acm.org/publications/class-2012-intro)
4. **The DL CCS page offers only the 2012 SKOS file.** Quote: "You may also opt to download
   the CCS SKOS file." It links `/pb-assets/dl_ccs/acm_ccs2012-1626988337597.xml` and the
   CCS how-to guide (`ccs-howto-v6-12jan2015.pdf/.docx`). The how-to PDF names 1998 only
   in the publication dates of its example papers.
   - https://dl.acm.org/ccs (snapshot https://web.archive.org/web/20250102082052/https://dl.acm.org/ccs)
   - https://www.acm.org/binaries/content/assets/publications/article-templates/ccs-howto-v6-12jan2015.pdf (snapshot https://web.archive.org/web/2024/https://www.acm.org/binaries/content/assets/publications/article-templates/ccs-howto-v6-12jan2015.pdf)
   - The older DL tree views (`ccs_flat.cfm`, `ccs.cfm`, 2017 snapshots) show the 2012 tree
     and a "Generate CCS Codes" tool, with no 1998 mapping:
     https://web.archive.org/web/20170626234533/http://dl.acm.org/ccs/ccs_flat.cfm ,
     https://web.archive.org/web/20170423173502/http://dl.acm.org/ccs/ccs.cfm
5. **The CCS 2012 SKOS file holds no mapping.** I downloaded
   https://dl.acm.org/pb-assets/dl_ccs/acm_ccs2012-1626988337597.xml directly (HTTP 200,
   613,931 bytes, sha256 `49f79117…dc045`, matching `schemes/acm-ccs/sources.lock.json`).
   Its only elements are `rdf:RDF`, `skos:ConceptScheme`, 2113 `skos:Concept`, 2113
   `skos:prefLabel`, 2100 `skos:broader`/`skos:narrower`, and 13
   `skos:hasTopConcept`/`skos:topConceptOf`. It has no `skos:*Match`, no notes and no
   1998 codes: the only "1998" in the file is the XML namespace URI, and no string matches
   the 1998 code pattern `[A-K].x.y`. The file is not kept in the repo.
6. **The 1998 CCS pages give no forward mapping.** The 1998 index and its introduction
   cover the 1998 tree and its history, with no link to 2012 equivalents.
   - https://www.acm.org/publications/computing-classification-system/1998 (snapshot https://web.archive.org/web/20250114004200/https://www.acm.org/publications/computing-classification-system/1998)
   - https://www.acm.org/publications/computing-classification-system/1998/ccs98-intro (snapshot https://web.archive.org/web/20250124090558/https://www.acm.org/publications/computing-classification-system/1998/ccs98-intro)
7. **Searches found nothing else.** Web searches for a CCS 1998/2012 crosswalk,
   concordance or mapping file (XLS, CSV, XML, SKOS) returned only the CACM statement
   above and secondary pages that repeat it. One secondary page found by search,
   http://taxonomies.labs.crossref.org/?p=109, refused the connection when fetched, so its
   wording is UNVERIFIED. Search snippets say it describes the same internal map that was
   "automatically run against all articles in the ACM Digital Library".

## Terms of use (relevant even if a mapping were found)

- CCS pages (2015 snapshot of http://www.acm.org/about/class/2012, cited above). Quote:
  "Permission to make digital or hard copies of portions of this work for personal or
  classroom use or research purposes is granted without fee provided that the copies are
  not made or distributed for profit or commercial advantage ... To copy otherwise, to
  republish, to post on servers, or to redistribute to lists, requires prior specific
  permission and/or a fee." Local research use would be allowed. Committing the data to
  this MIT/Apache repository would not.
- ACM DL policy, the "Terms of Usage" link on dl.acm.org/ccs. Quote: "Under no
  circumstances are the following actions permitted: ... Using scripts or spiders to
  automatically download articles or harvest metadata from the ACM Digital Library."
  So the per-article 1998/2012 term pairs on DL citation pages cannot be scraped to
  rebuild ACM's mapping. They also cover ACM-published articles only, not the arXiv
  papers in our corpus.
  - https://libraries.acm.org/digital-library/policies (snapshot https://web.archive.org/web/20251212013111/https://libraries.acm.org/digital-library/policies)

## What this means for the benchmark

- Corpus: 317 of 10,000 papers carry `acm_ccs`, with 690 labels over 142 distinct CCS 1998
  codes. The most frequent are `I.2.6` (65), `I.2.7` (64), `I.2.11` (32), `G.3` (30) and
  `F.2.2` (21). None is a `scheme:acm-ccs@2012` code, so `acm-ccs` gold stays "skipped".
- Options that need no invented mapping, none of them done here:
  - ask ACM (permissions@acm.org) for the internal 1998→2012 map under research terms;
  - build a separate CCS 1998 scheme and score against that instead, if a usable
    machine-readable 1998 source and its terms allow it;
  - use corpus papers that carry CCS 2012 CCSXML blocks, which arXiv metadata does not
    normally provide.
