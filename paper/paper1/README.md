# Paper 1: Scoring universal classification schemes with hierarchical-clustering objectives

**Status: DRAFT, not submitted.** Nothing here has been submitted, posted or
shared. The text is complete: every section is written, every number is
generated, and no citation is unresolved.

Candidate venues: JASIST, Knowledge Organization, JCDL, TPDL.

## Files

- `paper.md`: the draft (Markdown with pandoc-style `[@key]` citations).
- `references.bib`: references, generated by `docs/research/subset_bib.py`
  as the subset of `docs/research/references.bib` that `paper.md` cites.
  The comment above each entry records how it was verified (Crossref,
  arXiv API, proceedings page or page title).
- `scripts/make_tables.py`: generates every table and every marked number
  in `paper.md` (standard-library Python 3). The validity, stability, book
  and semantic-tier values come from `paper/common/extra_results.py`, which
  `paper/method-survey/scripts/gen_tables.py` also uses.

Prior work was searched systematically in
`research/reports/8-prior-work-search.md`; no unresolved citation markers remain.

## Rebuilding the tables

From the repository root:

```sh
python3 paper/paper1/scripts/make_tables.py          # rewrite generated parts of paper.md
python3 paper/paper1/scripts/make_tables.py --check  # exit 1 if paper.md is stale
```

Generated regions are delimited in `paper.md` by
`<!-- table:NAME -->` ... `<!-- /table:NAME -->` and inline
`<!-- v:NAME -->value<!-- /v -->`. Do not type numbers into them by hand.
To add a number to the prose, add a value to `build()` in the script and a
marker in the text. The script stops with an error on an unknown marker.
It also asserts that the r2 and r3 runs reused the 2026-10-10 graphs and
scheme files and that the corpus files match their recorded SHA-256.

`paper.pdf` is the rendered draft. To rebuild it, from `paper/paper1`:

```sh
pandoc paper.md --citeproc --bibliography references.bib --pdf-engine=xelatex \
  -H ../common/pandoc.tex -V mainfont="STIX Two Text" -V mathfont="STIX Two Math" \
  -V geometry:margin=1in -V fontsize=10pt -o paper.pdf
```
