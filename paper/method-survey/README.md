# Method and survey paper (Typst draft)

Working draft of "Scoring Library Classification Schemes with
Hierarchical-Clustering Objectives: A Survey of Open Schemes and a Common
Benchmark". Typeset with Typst as a classic two-column US Letter paper.

**Status: DRAFT, not submitted.** Nothing here has been submitted, posted or
shared. The text is complete: every section is written, every number is
generated, and no citation is unresolved. The author line is a placeholder
for the venue's form.

## Build

From the repository root:

```sh
typst compile paper/method-survey/main.typ paper/method-survey/main.pdf
```

Typst 0.15.1 was used. The template needs only fonts bundled with Typst
(New Computer Modern, New Computer Modern Math, DejaVu Sans Mono) and no
packages, so it compiles offline.

## Files

| file | role |
| --- | --- |
| `template.typ` | page, headings, equations, table and figure styles |
| `main.typ` | title block, abstract, section includes, bibliography |
| `sections/*.typ` | the sections of the paper |
| `generated.typ` | tables and headline values, generated from the result files |
| `scripts/gen_tables.py` | produces `generated.typ`; reads committed files only |
| `references.bib` | cited subset of `docs/research/references.bib`, generated by `docs/research/subset_bib.py` |
| `main.pdf` | compiled output |

To regenerate and check the numbers (no other branch is needed):

```sh
python3 paper/method-survey/scripts/gen_tables.py          # rewrite generated.typ
python3 paper/method-survey/scripts/gen_tables.py --check  # exit 1 if it is stale
```

## Where the numbers come from

Every table in Sections 5 to 9, and every number written as `#v.<key>` in
the text, is produced by `scripts/gen_tables.py` from files committed in this
repository. Nothing was recomputed by running the harness.

| used for | results directory |
| --- | --- |
| gold: `arxiv`, `jel`, `lcc`, `lcc-full`; placed (lexical@1) for the before/after table | `bench/results/2026-10-10/` |
| placed (lexical@2): every placed table, navigation, placement statistics | `bench/results/2026-10-10-r2/` |
| corrected MSC gold (ACM CCS gold still skipped) | `bench/results/2026-10-10-r3/` |
| fitted scheme | `bench/results/2026-10-10-learned/` |
| coverage control, dense against sparse cost | `bench/results/2026-10-10-covered/` |
| lexical against shortlist tier (preliminary; marked pending in `bench/results/README.md`) | `bench/results/2026-10-10-semantic/` |
| rank stability on the papers | `bench/results/2026-10-11-stability/` |
| book claims over 27 settings | `bench/results/2026-10-11-book-stability/` |
| judge agreement, false-join variants | `docs/validity/`, `bench/results/2026-10-11-falsejoin/` |
| cross-fit of the fitted scheme | `bench/results/2026-10-10-embed/` |
| corpus facts (counts, shares, edges, tau) | `bench/corpus/*.jsonl`, graphs under `bench/results/2026-10-10/graphs/`, through `paper/paper1/scripts/make_tables.py` |

The validity, stability, book, semantic-tier and external-signal values are
computed by `paper/common/extra_results.py`, which `paper/paper1` also uses.
Spearman and Kendall values are computed by the scripts from per-scheme
values.

* Table 1 and the prose of Section 2 (survey): taken from the scheme READMEs
  under `schemes/` and `data/schemes/lcc/`, and from
  `research/reports/1-open-schemes.md`, `4-licensing-crosswalks.md`,
  `5-acm-ccs-1998-2012.md` and `7-ddc-position.md`.
* Method (Section 3), related work and discussion: adapted from
  `paper/paper1/paper.md`.
* The prose of the fitted-scheme section and its caveats: from
  `paper/paper2/paper.md` and the learned results file.

## Notes

* `references.bib` is generated by `docs/research/subset_bib.py` as the subset
  of `docs/research/references.bib` that the `.typ` sources cite. The comment
  above each entry records how it was verified. Edit the shared file, not this
  copy. `python3 docs/research/subset_bib.py --check` must pass.
* Prior work was searched in `research/reports/8-prior-work-search.md`.
* The survey table reports what each publisher states about licensing at the
  date the project's reports were written. It is not legal advice.
* The default scheme of the tool that produced the placements is the
  bundled `lcc@2024`, LCC outline with LCSH vocabulary
  (`docs/decisions/default-scheme.md`); the paper's results do not depend on
  that choice.
