# Method and survey paper (Typst draft)

Working draft of "Scoring Library Classification Schemes with
Hierarchical-Clustering Objectives: A Survey of Open Schemes and a Common
Benchmark". Typeset with Typst as a classic two-column US Letter paper.
Marked DRAFT, not submitted. Author is `AUTHOR TBD`.

## Build

From the repository root:

```sh
typst compile paper/method-survey/main.typ paper/method-survey/main.pdf
```

Typst 0.15.1 was used. The template needs only fonts bundled with Typst
(New Computer Modern, New Computer Modern Math, DejaVu Sans Mono) and no
packages, so it compiles offline.

## Files

| file | role |
| --- | --- |
| `template.typ` | page, headings, equations, table and figure styles, `[cite?]` marker |
| `main.typ` | title block, abstract, section includes, bibliography |
| `sections/*.typ` | the sections of the paper |
| `generated.typ` | tables and headline values, generated from the result files |
| `scripts/gen_tables.py` | produces `generated.typ` with `git show`; reads no network |
| `references.bib` | cited subset of `docs/research/references.bib`, generated by `docs/research/subset_bib.py` |
| `main.pdf` | compiled output |

To regenerate the numbers (needs the `gitlab/*` branches below to exist):

```sh
python3 paper/method-survey/scripts/gen_tables.py > paper/method-survey/generated.typ
```

## Where the numbers come from

Every table in Sections 5 to 7, and every number written as `#v.<key>` in the
text, is produced by `scripts/gen_tables.py` from these committed files.
Nothing was recomputed by running the harness.

| used for | branch | results directory |
| --- | --- | --- |
| gold: `arxiv`, `jel`, `lcc`, `lcc-full`; placed (lexical@1) for the before/after table | `gitlab/dot-8mj8m.12` | `bench/results/2026-10-10/` |
| placed (lexical@2): every placed table, navigation, placement statistics | `gitlab/dot-8mj8m.12-rerun` | `bench/results/2026-10-10-r2/` |
| corrected MSC gold (ACM CCS gold still skipped) | `gitlab/dot-8mj8m.17-acm` | `bench/results/2026-10-10-r3/` |
| fitted scheme (Section 7) | `gitlab/dot-8mj8m.14` | `bench/results/2026-10-10-learned/` |

The header of `generated.typ` records the commit of each branch used.
Spearman and Kendall values are computed by the script from the per-scheme
skills. Values that are not in those files and were checked directly: $\tau$
and edge counts (graph manifests under `bench/results/2026-10-10/graphs/`),
the corpus composition and holdout letters (`bench/corpus/corpus.jsonl`,
`holdout.jsonl` on `gitlab/dot-8mj8m.12`).

## What is not generated

* Table 1 and the prose of Section 2 (survey): taken from the scheme READMEs
  under `schemes/` and `data/schemes/lcc/`, and from
  `research/reports/1-open-schemes.md`, `4-licensing-crosswalks.md` and
  `5-acm-ccs-1998-2012.md` (branches `gitlab/dot-8mj8m.12`,
  `gitlab/dot-8mj8m.19`).
* Method (Section 3), related work and discussion: from
  `paper/paper1/paper.md` (`gitlab/dot-8mj8m.13`), with corrections noted in
  the commit that added this directory.
* Section 7 prose and caveats: from `paper/paper2/paper.md`
  (`gitlab/dot-8mj8m.15`) and the learned results file.

## Open items

* `[cite?]` (the `#cq` marker in `template.typ`) marks a claim with no verified
  source. None is in use: every earlier marker was resolved with a verified
  source or the claim was rewritten. Prior work was searched in
  `research/reports/8-prior-work-search.md`.
* `references.bib` is generated by `docs/research/subset_bib.py` as the subset
  of `docs/research/references.bib` that the `.typ` sources cite. The comment
  above each entry records how it was verified. Edit the shared file, not this
  copy.
* The survey table reports what each publisher states about licensing at the
  date the project's reports were written. It is not legal advice.
