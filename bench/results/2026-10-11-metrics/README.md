# Metrics upgrade results

The 2026-10-11 results rescore 96 papers and 500-item holdout runs across MiniLM, BGE-small and Nomic at k=20, plus 108 scheme/placement runs on the 3,000 sampled books across the same three book graphs. Each score record has 1,000 item-bootstrap and 1,000 edge-bootstrap resamples and 200 seeded item-to-class permutations. The paired result files contain induced-subgraph item-bootstrap CIs for all numeric metrics and scheme pairs.

All logarithms use base 2. Navigation reports placed-only and all-item estimates with coverage, uniform and seeded Zipf(s=1) query workloads, and the a={0,1,2,4} branch-cost sweep. The alphabetic optimum is computed by a Knuth-optimized O(n^2) dynamic program. The sampled books have one record per work and no edition-count field, so no popularity proxy is available.

## Findings

- Every one of the 32 book-run `cost_norm` rankings from the prior proposal bootstrap is unchanged for each of the three embedding graphs. The recommendation ranking therefore does not change.
- Across the three book graphs, the real assignments have cost permutation z-scores from -475.09 to -40.59. The observed costs sit below the 200-permutation nulls; the null summaries include bootstrap CIs.
- The expected `a=0` base-2 branch cost is 1.035 to 1.706 times the alphabetic optimum across the book runs.

`results.json` contains the complete records and paired bootstrap outputs. `results.md` gives query workload estimates, CIs, null statistics and selected paired differences. The KB proposal tables are generated by `research/reports/scripts/kb_proposal_tables.py` and include the four main book schemes on each embedding graph.
