# False-join rescoring of the published runs

The Dasgupta cost sums `w_ij · |leaves(LCA(i, j))|` over similar pairs only, so
two dissimilar works joined deep cost nothing (`docs/validity/README.md`,
stratum B). This directory rescores every published run with a false-join
term added (`crates/bench/src/falsejoin.rs`). Older result directories are not
touched. Every number here is regenerated by
`crates/bench/scripts/falsejoin_rescore.py`, `external_signals.py` and
`falsejoin_validity.py`.

## The term

- **Negative sample** (`negatives/<universe>-<model>-k<k>.json.gz`). These
  are drawn from the kNN complement. For each item, seeded uniform draws
  (seed 20261010) pick other items until 10 pairs are accepted. A pair is
  accepted when it is not an edge of the graph and its cosine is below the
  floor, the graph's τ (its mean pair cosine). Each pair's weight is
  `d = τ − cos`. Every kNN pair above τ is a graph edge, so the sample never
  holds a pair that the Dasgupta term rewards joining. The file has the
  graph format; `tau` is the floor and `k` the pairs per item. The
  `.manifest.json` next to it gives the graph, vectors and output hashes.
- **Outside-mass form** `FJ = Σ d (n − |leaves(LCA)|) / (n Σ d)`. This is
  one minus the dissimilarity objective of Cohen-Addad et al.
  (`cohenaddad2017`), which maximises `Σ d |leaves(LCA)|`, normalised by
  `n Σ d`. A pair
  that meets in a main class holding a tenth of the library already pays
  0.9 of the maximum, so this form charges *shallow* joins almost as much
  as deep ones, and it rewards a wide top level.
- **Specificity form** `FJs = Σ d ln(n / |leaves(LCA)|) / (ln n Σ d)`. This is
  the information content of the class where the pair meets: every halving
  of that class adds the same charge, so deep joins cost more than shallow
  ones. Report 9 uses this form as the primary correction.
- **Combined objective** `C + β · FJ` and `C + β · FJs`, with β = 1 as the
  stated weighting: equal weight for the two error types per unit of
  normalised cost. The runs record β ∈ {0.25, 0.5, 1, 2, 4, 8}
  (`cfj_b<β>`, `cfjs_b<β>`).

Both forms are 0 when every dissimilar pair meets at the root. An unplaced
item hangs off the root, so it adds nothing to FJ; the Dasgupta term already
charges it the maximum.

## Contents

- `negatives/`: the 15 negative samples. They cover the books (3,000) at
  k = 10, 20 and 50, and the papers (10,000) and the title-only holdout
  (500) at k = 20, each for MiniLM, bge-small and nomic.
- `bootstrap/<universe>-<model>-k<k>.json.gz`: one call per graph of
  `shelfmark-bench bootstrap --negatives`. Each call scores every published
  run of the universe on the same 1,000 paired item draws (seed 20261010):
  the 2026-10-11-metrics runs plus report 9's runs. It gives point values, CIs
  and paired differences for all metrics, including `fj_norm`, `fjs_norm`
  and every combined objective. `.draws.json.gz` keeps each draw's
  cost_norm, fj_norm, fjs_norm, nav_log_a1, coverage and mean_depth.
  `cost_norm_checked` records that every run's cost_norm equals its
  published value to 1e-9: all 420 run × graph values matched.
- `runs/<model>-k<k>/<universe>/<run>.json`: per-run records with the point
  value and 95% interval of every false-join score.
- `results.md` / `results.json`: all runs, sorted by C + FJs.
- `external/`: the non-LLM validity signals and their agreement with each
  metric variant (see below).

## Inputs and reproducibility

The Dasgupta term uses the published graphs, unchanged. The negatives need
cosines of non-edge pairs, so the vectors were rebuilt with
`build_graph_fastembed.py --vectors`, using the pinned models, fastembed 0.9.0
and onnxruntime 1.31.0 (nomic: `--max-length 512`, as published). On this
machine the rebuilt vectors are not bit-identical to the published ones. The
MiniLM books graph rebuilt from them has edge weights within 8.4e-7 of the
published graph, and one of its 42,657 edges differs; the MiniLM corpus graph
is within 9.6e-7, with one of 148,111 edges different. The thread count does
not change this. Since the samples are committed, rescoring does not need the
vectors; redrawing them on another machine can change pairs whose cosine is
within about 1e-6 of τ.

Seven paper schemes (ACM CCS, EuroVoc, ILC2, IPC, JEL, LCC-full and MSC) are
fetch-and-build only. Their scheme files come from
`crates/bench/scripts/build_schemes.sh`. All 13 built with the hashes of the
published records, and `runs_spec` names them `build_schemes.sh:<name>.json`.

## External signals (`external/`)

- `openalex.jsonl.gz`: for each of the 10,000 arXiv papers, the OpenAlex
  work found through its arXiv DOI, its `referenced_works`, and the works
  citing it. Data is CC0 from https://api.openalex.org. The fetch used DOI
  filters batched 50 per request, at most one request per 1.1 s, the
  `mailto` parameter and an on-disk cache. 9,623 papers were found. Only 1,615
  have references and 1,403 are cited; most of the corpus is 2025–26
  preprints, which OpenAlex holds without reference lists.
- `lcsh.jsonl.gz`: the Library of Congress subject headings of each of the
  3,000 books, from the Open Library `subjects` field. All-capitals
  BISAC-style terms are dropped, and headings are normalised.
- `pairs-<signal>.jsonl.gz` and `.meta.json`: per signal, up to 4,000 seeded
  related and 4,000 unrelated pairs, with each pair's cosine under each model.
  - Bibliographic coupling: related pairs share a reference.
  - Co-citation: related pairs share a citing work.
  - LCSH: related books share a heading held by at most 30 books.
  - Unrelated pairs are covered items that share no feature.
- `agreement.md` / `agreement.json`: per-pair AUC and κ, and per-scheme ρ, of
  every metric variant against these signals, plus the external separation
  of every run.

**Independence.** Citations are independent of both the embedding and the
class numbers. The LCSH headings are independent of the class *number*, but
the books' embedding text is mostly those same headings, and LC assigns
headings and call numbers in the same cataloguing record. So the LCSH check
is a librarian signal distinct from the class number, not one independent of
the graph or of LCC.

## Reproduce

```sh
export PATH=/usr/local/cargo/bin:$PATH
cargo build --release -p shelfmark-bench
crates/bench/scripts/build_schemes.sh          # the seven fetch-and-build paper schemes
# vectors (only to redraw the negatives): for each model and corpus
#   build_graph_fastembed.py bench/corpus/<corpus>.jsonl g.json m.json --model <model> \
#     [--max-length 512 for nomic] --vectors bench/corpus/cache/falsejoin/vectors/<model>-<corpus>.f32
python3 -I crates/bench/scripts/falsejoin_rescore.py all --harness <target>/release/shelfmark-bench
python3 -I crates/bench/scripts/external_signals.py openalex   # cached; polite fetch on first run
python3 -I crates/bench/scripts/external_signals.py lcsh
python3 -I crates/bench/scripts/falsejoin_validity.py judge
python3 -I crates/bench/scripts/falsejoin_validity.py sample  # needs the vectors
python3 -I crates/bench/scripts/falsejoin_validity.py external
```

`falsejoin_rescore.py` skips any output that already exists, unless given
`--force`. It runs at most two scoring jobs at a time.
