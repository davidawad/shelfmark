# Book-side rank stability of report 9's claims

Generated by `generate_book_stability.py publish`; method in `REPRODUCE.md`. Settings: 3 embedding models × k ∈ {10, 20, 50} × 3 graph thresholds (q00 = published graph, q25, q50), 27 each for the 3,000 books, the 500-book title-only holdout (27) and, for the placed runs only, the 10,000 papers (0). Objectives (lower is better): C = cost_norm; J = C + 0.002·N; C + FJs; J′ = C + FJs + 0.002·N, with N = nav_log_a1 and FJs the specificity false-join term at β = 1. Intervals are 95% paired item-bootstrap percentiles (1,000 draws, seed 20261010). Every unthresholded setting reproduces the published false-join points to 1e-9 (348 run × setting checks).

A ranking claim passes when the minimum Spearman ρ over all setting pairs is ≥ 0.8. A pair claim is **STABLE** when the paired difference has the claimed sign in every setting and no setting's 95% CI excludes zero the other way; **MOSTLY** when the sign matches in ≥ 80% of settings with no significant reversal; otherwise **NOT STABLE**. A tie claim is stable when no setting's CI excludes zero. `lcc-lcsh-placed` is the scheme the `shelfmark` binary bundles (the LCC outline plus LCSH vocabulary) placed by the same classifier as the other `-placed` runs (`placements/`).

## Bead rule: highest placed skill, coverage ≥ 0.80, ties by nav_log_a1

Placed runs only: every scheme placed by the same lexical classifier on the same items. Skill is (1 − C) / (1 − C_ref) against the setting's average-linkage reference, so within a setting it orders runs as C does.
