# docs/research: citation index and source PDFs

Index of the publications, standards, classification-scheme pages, datasets and
tools that shelfmark builds on (papers 1 and 2, the method-survey draft, and
research reports 1-5 and 8). Built 2026-10-10 and re-checked the same day:
every bib entry against Crossref, DataCite, the arXiv API or the publisher
page (see the `% verified:` comment above each entry in `references.bib`). Every URL below was fetched with curl on that date; the HTTP
status is in the status column. Nothing here was repaired from memory.

## What is committed, what is local-only

| Item | Where | In git |
| --- | --- | --- |
| Citation index (this file) and `references.bib` | `docs/research/` | yes |
| PDFs under an open licence (CC BY, CC BY-SA, CC0, public domain), licence read from the source page or the PDF itself | `pdf/open/` (14 files) | yes |
| All other PDFs (author- or publisher-posted, for personal reading) | `pdf/restricted/` (34 files) | no (gitignored; `.gitkeep` only) |
| Web pages and datasets | not mirrored; URL and access date only | n/a |

Committed PDF total: 13.9 MB (13,869,035 bytes; under the 50 MB threshold).

Rules applied: arXiv papers are restricted unless the arXiv abs page shows a CC
licence. Non-commercial (NC) and no-derivatives (ND) licences are treated as
restricted. A licence statement found only in an aggregator or via a Crossref
record, without the source page or PDF showing it, is not enough to commit.

## Re-fetch

```
bash docs/research/fetch.sh            # all listed PDFs
bash docs/research/fetch.sh open       # only pdf/open
bash docs/research/fetch.sh restricted # only pdf/restricted
```

The script skips files that exist, waits 3 s between requests to the same host,
keeps a download only if it starts with `%PDF`, and exits non-zero if any
download failed.
