# IPC scheme: sources

Generated by `src/shelfmark/schemes/ipc/builder` (`ipc-scheme build`); do not edit by hand.
`ipc.json` is scheme `ipc@2026.01` with 80145 classes and validates against
`src/shelfmark/schemas/scheme.schema.json` and `shelfmark_core::scheme::SchemeDoc`.

## Rebuild

```sh
cd src/shelfmark/schemes/ipc/builder
cargo run --release -- fetch --cache /tmp/ipc-sources   # network; rewrites sources.lock.json
cargo run --release -- build --cache /tmp/ipc-sources   # offline; deterministic from the lock
cargo run --release -- check --cache /tmp/ipc-sources   # fails if ipc.json or SOURCES.md is stale
```

`build` refuses any cached archive, or XML member inside it, whose sha256 differs from
`sources.lock.json`. `fetch --edition YYYYMMDD` pins another edition.

## Links to LCC and LCSH

None. The IPC master files (scheme, catchword index, concordance, definitions) link only
to IPC symbols and earlier IPC editions; WIPO publishes no IPC-to-LCC or IPC-to-LCSH
mapping, so the scheme carries no `lcc` or `lcsh` vocabulary.
