# FDC scheme: sources

Generated by `schemes/fdc/builder` (`fdc-scheme build`); do not edit by hand.
`fdc.json` is scheme `fdc@0.06` with 1097 classes and validates against
`schemas/scheme.schema.json` and `shelfmark_core::scheme::SchemeDoc`.

## Rebuild

```sh
cd schemes/fdc/builder
cargo run --release -- fetch --cache /tmp/fdc-sources   # network; rewrites sources.lock.json
cargo run --release -- build --cache /tmp/fdc-sources   # offline; deterministic from the lock
cargo run --release -- check --cache /tmp/fdc-sources   # fails if fdc.json or SOURCES.md is stale
```

`build` refuses a cached file whose sha256 differs from `sources.lock.json`.
