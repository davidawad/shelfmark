# Basic Classification (BK) scheme

`bk.json` is scheme `bk@2026-10-03`: the Basisklassifikation (Dutch
*Nederlandse basisclassificatie*, NBC), a hierarchical decimal subject
classification for scholarly works, maintained by the Gemeinsamer
Bibliotheksverbund (GBV). Official page:
<https://wiki.k10plus.de/spaces/K10PLUS/pages/118063148/Basisklassifikation>.
It validates against `schemas/scheme.schema.json` and is generated by this
crate (`bk-scheme build`), so do not edit it by hand.

```sh
shelfmark scheme compile schemes/bk/bk.json   # preview, then --commit
```

## Source

The GBV's DANTE service publishes a full JSKOS export, refreshed weekly:
<https://dev-download.dante.gbv.de/exports/bk/default/bk__default.jskos.ndjson>
(one concept per line; linked from the DANTE export listing at
<https://dev-api.dante.gbv.de/exports/>). The lock pins the export of
2026-10-03 (the scheme version): 6,540,863 bytes,
sha256 `aadabfeac8718e6a544a65b7e253233c67f0b75a785a44eee863ecb789a8391e`.
Because the URL is a rolling file, a later fetch will usually not match the
lock; `build` then fails and names both hashes.

## What is in it

- **Classes:** 2,140 (BARTOC says 2,139; the export has one more, `74.50X`,
  a class marked in its own note as deleted, "wird gelöscht, nicht mehr
  verwenden", which is kept so old records stay placeable).
- **Hierarchy:** each class's parent is the first entry of its JSKOS
  `ancestors`. The builder checks that every parent exists, that ancestor
  chains agree with the parent's own, and that `narrower` lists agree with
  the parents. Five roots (`0`, `1-2`, `3-4`, `5`, `7-8`), then two-digit
  headings (`01`), then decimal classes (`01.10`, `42.82`). Siblings are in
  code order.
- **Labels:** the German preferred label.
- **Vocabulary:** English preferred labels (2,100, source `bk-en`, weight
  0.9) and German alternative labels (145, source `bk-alt`, weight 0.8), so
  German and English queries both match. Terms equal to the label are
  dropped, and the 5 roots, a few other classes and empty English labels
  have no English term.
- **Notes:** scope note, definition and cross-reference note, as
  `Scope: ... | Definition: ... | Note: ...`. The 53 headings (JSKOS
  `GuideTerm`, not used for indexing) start with `Heading only; not used for
  indexing.`.
- **Code grammar:** `[0-9]{1,2}(-[0-9]{1,2})?(\.[0-9]{2}X?)?`.
- **No LCC or LCSH links:** the export carries no mappings, so search
  matches labels and the terms above. (coli-conc holds a few BK-to-DDC and
  BK-to-RVK mappings; they are not imported.)

## Build

```sh
cd schemes/bk
cargo run --release -- build --cache /tmp/bk-sources   # fetches if missing; writes bk.json
cargo run --release -- check --cache /tmp/bk-sources   # fails if bk.json is stale
```

If the GBV has refreshed the export, `cargo run -- fetch --cache DIR
--relock` re-pins the lock; then set `version` in the lock to the export
date (it is part of every class ID) and rebuild.

## Tests

```sh
cargo test                                             # fixture + committed bk.json; no network
BK_CACHE=/tmp/bk-sources BK_REQUIRE_SOURCE=1 cargo test --test source   # also rebuilds bk.json from the export
```

Without `BK_CACHE`, the rebuild test appends a `SKIP:` line to
`$TEST_SKIP_LOG`; `BK_FETCH=1` downloads the export into an empty cache.
`cargo clippy --all-targets -- -D warnings` is clean.
