# arXiv category taxonomy scheme

`arxiv.json` is scheme `arxiv@2024-04-01`: arXiv's category taxonomy
(<https://arxiv.org/category_taxonomy>) as a shelfmark scheme file. It
validates against `schemas/scheme.schema.json`. It is
generated by `builder/` (`arxiv-scheme build`), so do not edit it by hand.

The scheme is registered as known but not compiled into the binary. To
compile it into a store:

```sh
shelfmark scheme compile schemes/arxiv/arxiv.json   # preview, then --commit
```

## What is in it

- **Hierarchy:** group (`grp_physics`) > archive (`cond-mat`) > category
  (`cond-mat.mtrl-sci`). There are 8 groups, 38 archives (18 of them
  retired) and 192 classes.
- **Single-category archives:** where a category has its archive's id
  (`hep-th`, `quant-ph`, or the legacy bare `astro-ph`), the archive and the
  category are one class.
- **Retired archives:** archives such as `acc-phys` and `alg-geom` stay
  under their group, with a note naming the category that took them over.
  This keeps old identifiers like `acc-phys/9411001` placeable.
- **Notes:** each class's note carries arXiv's description. It also
  records aliases (`math.MP` is an alias of `math-ph`, `stat.TH` of
  `math.ST`, and so on), the retired archive a category took over, and the
  dates until which old submissions could use a bare archive name.
- **Dropped:** the test and invalid groups, and their archives and
  categories.
- **Code grammar:** `grp_<name>`, `<archive>`, or
  `<archive>.<subject>`, where the subject is two capitals (`cs.AI`) or
  lowercase words (`physics.optics`).
- **No LCC or LCSH links:** the source provides none. Its descriptions
  cite ACM classes only. So no class carries `vocab` links, and search
  matches labels.

## Provenance and rebuild

`sources.lock.json` pins each input: URL, arxiv-base commit, last-change
date, fetch date, size and sha256. The two MIT files are committed under
`sources/`. The scheme version is the date of the last commit that changed
`definitions.py`. The scheme's `source.description` repeats the commit and
the hashes.

```sh
cd schemes/arxiv/builder
cargo run --release -- fetch --cache /tmp/arxiv-cache   # network; refreshes sources/ and the lock
cargo run --release -- build --cache /tmp/arxiv-cache   # offline; cross-checks the page, writes arxiv.json
cargo run --release -- check [--cache /tmp/arxiv-cache] # fails if arxiv.json is stale
cargo test                                              # also rebuilds from sources/ and compares
```

`build` cross-checks the cached page. Every category on the page must be a
class with the same name under the same group and archive, and every active
category must be on the page. The build reads only files whose sha256
matches the lock.
