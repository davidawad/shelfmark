## Rebuild

```sh
cd schemes/fast
cargo run --release -- fetch --cache /tmp/fast-sources   # network; verifies sha256 against the lock
cargo run --release -- build --cache /tmp/fast-sources   # offline, deterministic: out/fast.json, fast-sample.json, SOURCES.md
cargo run --release -- check --cache /tmp/fast-sources   # fails if any of the three is stale
```
