# LCC outline scheme: sources

Generated by `tools/lcc-outline` (`lcc-outline build`); do not edit by hand.
`lcc.json` is scheme `lcc@2024` with 7392 classes and validates against
`schemas/scheme.schema.json` and `shelfmark_core::scheme::SchemeDoc`.

## Rebuild

```sh
cd tools/lcc-outline
cargo run --release -- fetch --cache /tmp/lcc-sources   # network; rewrites sources.lock.json
cargo run --release -- build --cache /tmp/lcc-sources   # offline; deterministic from the lock
cargo run --release -- check --cache /tmp/lcc-sources   # fails if lcc.json or SOURCES.md is stale
```

`build` refuses any cached file whose sha256 differs from `sources.lock.json`.
